Problem Statement 03

From Requirements to Code —
AI-Generated C3 Integration Gateway

Build an agentic AI prototype that interprets C3 integration requirements and automatically generates standards-compliant gateway code.

Background

Translating C3 integration requirements into integration gateway code is a structured, rule-bound process that nonetheless remains heavily manual. Engineers must repeatedly parse requirements, apply domain-specific patterns, and hand-craft code that meets gateway standards — work that is time-consuming, error-prone, and inconsistent across individuals and teams.

With agentic AI now sufficiently mature, there is a clear opportunity to build an AI agent that understands the semantics of C3 integration requirements and autonomously generates accurate, standards-compliant gateway code — compressing the time from requirement to deployment and freeing engineers to focus on higher-order problems.

Your mission

Using the provided starter pack — which includes an example integration schema, connection type references, and Eurocontrol ASTERIX standards — build an agentic AI prototype that interprets integration requirements and automatically generates standards-compliant gateway code as output.

Begin by studying the provided materials to understand the patterns, rules, and logic that engineers currently apply manually. Then design an agentic workflow that replicates and automates this translation — demonstrating a working end-to-end flow from requirement ingestion to code generation, wrapped in an interface that a user can actually interact with.

The best submissions will go beyond mechanical code generation to show intelligent handling of ambiguity — where requirements are incomplete, conflicting, or underspecified, how does your agent reason, flag, or resolve the gap?

Starter pack — provided to all teams
What you will receive
An example integration schema to illustrate the structure and format your gateway code should conform to
Reference notes on types of connections — including broker-based connections and other common integration patterns used in C3 environments
Eurocontrol ASTERIX standards documentation — the target data format your integration gateway should be able to handle
Sample online ASTERIX decoders as reference tools to validate and cross-check your generated output
Tip
The starter pack is a baseline, not a ceiling. Teams are encouraged to extend beyond the provided examples once the core flow is working.
Suggested starting points — you are not limited to these
Accessible
Use an AI coding assistant to study the provided examples and manually identify the translation patterns, then document these as a structured rule set that could form the basis of an automated pipeline.
Build a simple prompt-based prototype where an LLM accepts a requirement as input and generates a first-cut gateway code output, validated manually against the reference standards.
Intermediate
Design an agentic workflow that ingests a requirement, applies the identified translation patterns, generates gateway code, and runs a validation step to check adherence to gateway standards before presenting output to the user.
Build a conversational interface where an engineer can submit a requirement, review the generated code, provide feedback, and have the agent iteratively refine the output.
Advanced
Implement a multi-step agent that not only generates gateway code but actively reasons through ambiguous or underspecified requirements — asking clarifying questions, surfacing assumptions, and flagging risks before committing to an output.
Build an evaluation harness that automatically scores generated gateway code against the reference outputs, enabling rapid iteration and benchmarking of different agentic approaches.
