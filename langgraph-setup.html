Developer Setup Guide

LangChain + LangGraph + LangSmith

LangChain is the base library. LangGraph builds on top of it to orchestrate agents. LangSmith traces and debugs them. This guide gets all three set up.

API credits are provided via Zenmux — your key will be sent in the group chat. You don't need your own API key to get started.
Setup steps
1
≈ 30–45 min
Install LangChain, LangGraph & dependencies
LangChain is the foundation library — LangGraph is built on top of it. You need both. The LangChain Academy course installs everything together in one go.
Python version — important
LangGraph requires Python 3.11, 3.12, or 3.13. Check yours before starting: python3 --version. If you're on 3.10 or below, upgrade Python first.

2
≈ 10 min
Test your connection via Zenmux
Run the notebook below to verify your environment is wired up correctly before you start building.
API key
Your Zenmux API key will be sent in the group chat. Replace <INSERT_API_KEY> in the notebook below before running.
Install the required package
# Make sure your virtual environment is active first, then:
pip install langchain-openai
Connection test notebook
Notebook — Required
Zenmux Connection Test
Download →
Download the notebook, open it in VS Code or Jupyter, insert your API key, and run all cells. Or copy the code below directly into a .py file.
import os
from langchain_openai import ChatOpenAI

# Initialize the ChatOpenAI model, pointing to the ZenMux gateway
llm = ChatOpenAI(
    model="gpt-4o",  # or claude-sonnet-4-5, gemini-3-pro, etc.
    temperature=0.2,
    openai_api_key="<INSERT_API_KEY>",
    openai_api_base="https://zenmux.ai/api/v1"  # ZenMux base URL
)

# Use invoke to test your connection
response = llm.invoke("What is the capital of Singapore?")
print(response.content)
Note — openai_api_base
The openai_api_base parameter is what redirects all API calls to Zenmux instead of OpenAI. Make sure this is set to https://zenmux.ai/api/v1 — if it's missing or wrong, your calls will go to OpenAI and fail with an authentication error.
Expected output
You should see: The capital of Singapore is Singapore City.
If you get an authentication error, double-check your API key has no extra spaces.
The notebook runs without errors and prints a response. You're connected to Zenmux and ready to build.

Setup — Required
Sign up at smith.langchain.com
Sign Up →
  • After login, go to Settings → API Keys
  • Click Create API Key — copy it immediately (shown only once)
  • Optionally create a project (e.g. my-langgraph-agent) to group your runs
Enable tracing via environment variables
# .env  (or export in your shell)
LANGSMITH_API_KEY=lsv2_pt_<your-key-here>
LANGSMITH_TRACING=true
LANGCHAIN_PROJECT=my-langgraph-agent
Using Jupyter or Colab?
Set environment variables inline instead:
import os
os.environ["LANGSMITH_API_KEY"] = "lsv2_pt_..."
os.environ["LANGSMITH_TRACING"] = "true"
Run your agent, open smith.langchain.com, and see full traces — every LLM call, tool invocation, and state snapshot — on the free tier.
Going further — continue on your own
Want unlimited local inference?

The Zenmux API key has limited credits. If you want a free, unlimited alternative — whether before, during, or after the hackathon — use Ollama, a local LLM runner that works entirely offline with no API costs and no rate limits. The code is identical; only the model initialisation line changes.

Download — Required
Install Ollama
Download →
One installer for macOS, Windows, and Linux. Runs as a background service on http://localhost:11434 automatically.
  • macOS / Windows: download the installer and run it
  • Linux: curl -fsSL https://ollama.com/install.sh | sh
  • Verify: ollama --version should print a version string
Pull a model (pick by RAM)
# ≥ 8 GB RAM — recommended
ollama pull llama3.1:8b

# ≥ 16 GB RAM — better reasoning
ollama pull qwen3:8b

# Low RAM (4–8 GB)
ollama pull llama3.2:3b

# Confirm the model is ready:
ollama list
Tool calling note
Models smaller than 7B may inconsistently decide when to call tools. If your agent loops or ignores tools, switch to a larger model. qwen3:8b and llama3.1:8b are the most reliable choices.
Swap one line in your agent
# Install the integration package
pip install langchain-ollama

# Replace this (Zenmux):
# from langchain_openai import ChatOpenAI
# llm = ChatOpenAI(model="gpt-4o", openai_api_key="...", openai_api_base="https://zenmux.ai/api/v1")

# With this (Ollama — no API key needed):
from langchain_ollama import ChatOllama
llm = ChatOllama(model="llama3.1:8b")  # or qwen3:8b

# Bind tools exactly the same way:
llm_with_tools = llm.bind_tools(tools)
Potential issues

⚠ create_react_agent deprecated in LangGraph v1.0 — Replaced by create_agent or raw StateGraph. If you see create_react_agent in old blog posts, follow the official tutorial instead.

⚠ LangGraph Platform renamed — As of Oct 2025, "LangGraph Platform" is now called LangSmith Deployment. This guide doesn't use deployment features, but be aware if you encounter the old name in docs or blog posts.
